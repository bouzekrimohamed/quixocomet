# Page de téléchargement

La page est publiée par GitHub Pages à l'adresse :
https://bouzekrimohamed.github.io/quixocomet/download/

Les liens Windows et Linux pointent vers les archives de la release GitHub
`v1.0.0`. La version macOS est desactivee tant que sa valeur vaut `null`.

Apres extraction du build Linux :

```bash
chmod +x QuixoQomet.x86_64
./QuixoQomet.x86_64
```

Si le nom varie, utiliser `chmod +x *.x86_64` puis `./*.x86_64`.

Contact en cas de probleme urgent :
[lm_bouzekri@gmail.com](mailto:lm_bouzekri@gmail.com)

Pour publier une nouvelle version, modifier uniquement les valeurs de
`DOWNLOADS` dans `app.js`. Les archives doivent rester dans GitHub Releases et
ne doivent pas etre ajoutees au depot.
