02

Installation Windows

  1. Telecharger BuildWindows.zip.
  2. Faire un clic droit sur le ZIP puis Extraire tout.
  3. Ouvrir le dossier extrait.
  4. Double-cliquer sur le fichier .exe.

Windows peut afficher SmartScreen ou Smart App Control au premier lancement. C'est normal pour un build etudiant non signe : choisir Informations complementaires puis Executer quand meme. Aucune desactivation de l'antivirus n'est demandee.

03

Installation Linux

  1. Telecharger BuildLinux.zip.
  2. Extraire le ZIP.
  3. Ouvrir un terminal dans le dossier extrait.
  4. Lancer les commandes ci-dessous.
chmod +x QuixoQomet.x86_64
./QuixoQomet.x86_64

Si le nom du fichier varie :

chmod +x *.x86_64
./*.x86_64

Garder dans le meme dossier : le fichier .x86_64, le dossier _Data et UnityPlayer.so. Sinon le jeu ne demarre pas.

05

Premier lancement

  1. Sur l'ecran d'authentification : Inscription puis email, username et mot de passe.
  2. Creer un compte puis se connecter avec email ou username.
  3. Mot de passe oublie : saisir l'email puis cliquer sur Mot de passe oublie.

Pour cette version de demonstration, la confirmation email n'est pas obligatoire.
